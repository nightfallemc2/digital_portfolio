# Hilkiah Mwanza | Portfolio
Static multi-page site: `index.html` (portfolio), `services.html`, `blog.html`.
- Banner: three slides, each with a profile photo on the right and themed art on the left. Add your own left images as `assets/slide-1.jpg`, `slide-2.jpg`, `slide-3.jpg` to replace the built-in art.
- Profile photo: put `assets/profile.jpg` in the repo (visitors' "Change photo" only changes their own browser view).
- Quote: edit the text in `index.html` (the on-page edit saves only in your browser).
- Blog: add entries to `posts.js`.
- Deploy: push to GitHub, then Settings > Pages > deploy from `main` / root.
